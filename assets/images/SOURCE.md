# Where the pictures come from

`appwizard` at 32 and 16 px is copied unchanged from the Windows 95 shell's
icon set (wippy-windows/windows, `assets/icons/SOURCE.md`): Microsoft's
artwork from `shell32.dll` (the Windows 98 `w98_appwizard.ico`), extracted to
RGBA PNG. It is Microsoft's artwork, not part of this module under MIT; the
file name is the picture's name in the pack, `windows.appwiz:images/appwizard`.
